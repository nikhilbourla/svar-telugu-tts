# Svar – Telugu Text-to-Speech

**Svar** is an experimental Telugu Text-to-Speech (TTS) model developed by Nikhil. It generates Telugu speech with male and female voice options using custom Transformer and Diffusion Transformer architectures.

### Explore Svar

- 🤗 **Hugging Face Model:** https://huggingface.co/copycat1/svar-telugu-tts
- 🎧 **Try the Demo:** https://huggingface.co/spaces/copycat1/svar-telugu-tts-demo

### Highlights

- Telugu speech generation.
- Male and female voices.
- Custom T2S Transformer and Diffusion Transformer.
- Approximately 52 million combined parameters.
- WAV audio output at 24 kHz.

### Repository Contents

This repository contains the inference implementation and application code required to run Svar.
